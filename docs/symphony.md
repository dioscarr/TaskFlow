# Agent Symphony System

## Overview

The Agent Symphony is a multi-agent orchestration system that coordinates specialized AI agents to complete complex objectives. All agents now follow the **Senior Full-Stack Software Architect** system prompt, ensuring production-quality output.

## Core Components

### 1. Centralized Prompts (`src/lib/agents/prompts.ts`)

Contains the default system prompts used by all agents:

- **`SOFTWARE_ARCHITECT_PROMPT`**: The base prompt enforcing production-quality standards
- **`ORCHESTRATOR_AGENT_PROMPT`**: For agents coordinating multi-step workflows
- **`WORKER_AGENT_PROMPT`**: For specialized task execution
- **`COGNITIVE_AGENT_PROMPT`**: For planning and strategic analysis

### 2. Agent Symphony (`src/lib/agents/AgentSymphony.ts`)

The main orchestration engine that:
- Creates execution plans from objectives
- Delegates tasks to specialized workers
- Reviews and synthesizes results
- Generates stakeholder-ready summaries

### 3. Cognitive Agent (`src/lib/agents/CognitiveAgent.ts`)

The "brain" that:
- Analyzes user requests
- Generates strategic execution plans
- Suggests specialist delegation

## Usage

### Triggering Symphony

```typescript
const symphony = new AgentSymphony({
  orchestrator: orchestratorModel,
  critic: criticModel,
  workers: {
    developer: developerModel,
    designer: designerModel,
    researcher: researcherModel
  },
  options: {
    logger: async (msg, type) => {
      console.log(`[${type}] ${msg}`);
    }
  }
});

const result = await symphony.run("Build a todo app with Prisma");
```

### Viewing Activity

Activity is logged to the database and displayed in the UI:
- Status bubble shows real-time thinking
- Activity feed shows full history
- Summaries are generated at completion
