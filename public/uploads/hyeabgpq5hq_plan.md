## Phone Company App - UI Plan

**Core Features:**

*   Dialer: A screen with a number pad for making calls.
*   Contacts: A list of contacts with search functionality.
*   Call History: A list of recent calls with details.

**UI Components:**

*   Button: Reusable button component with different styles.
*   Input: Reusable input component for phone numbers and search.
*   ContactCard: Component to display contact information.
*   CallLogItem: Component to display call history item.

**Technology Stack:**

*   Next.js 14+
*   TypeScript
*   Tailwind CSS
*   Shadcn/UI
